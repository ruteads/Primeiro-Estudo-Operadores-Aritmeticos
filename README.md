Operadores Aritméticos em Java 🧮

Projeto em **Java** para praticar sintaxe básica, operadores aritméticos, entrada de dados pelo teclado e formatação de saída.  
O programa simula a compra de itens (pão, queijo, maçã), aplica um desconto e calcula valores divididos e mensais.

📌 Funcionalidades
- Uso de operadores aritméticos: soma, subtração, multiplicação e divisão.
- Entrada de dados com `Scanner`.
- Saída formatada com `DecimalFormat` (duas casas decimais).
- Exibição de um resumo detalhado da compra.

 🖥️ Exemplo de execução
Digite o valor do pão: 10.50
Digite o valor do queijo: 4.50
Digite o valor da maçã: 3
Digite o valor do desconto: 4
Digite o número de dias do mês: 30

Resumo da compra:
Valor da compra: R$18,00
Com desconto: R$14,00
Dividido entre 2: R$7,00
Mensal: R$420,00

Conceitos praticados

Sintaxe básica em Java.

Operadores aritméticos (+, -, *, /).

Entrada e saída de dados (Scanner, System.out.println).

Formatação de números (DecimalFormat).
